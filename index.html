  • 사내 Confluence·Jira를 MCP로 연결
  • 사내 지식 검색 에이전트를 원격 MCP로 연동
  • 위키·Jira 자동 업데이트, 회의 자동화 파이프라인
  • 부서별 모닝 브리핑 에이전트 추진
5사용자 채널메신저, 웹, 사내 도구 등 업무 접점

주요 업무

전략부터 실행까지

항목을 누르면 자세한 내용이 펼쳐집니다.

  • RDB, HDFS, MongoDB 등 이기종 데이터 플랫폼을 운영하는 데이터 엔지니어링 조직 관리
  • 시스템·클라우드 엔지니어링 조직을 통해 온프레미스와 클라우드 인프라 운영
  • 보안 조직을 개발그룹 안에 두어 개발·인프라와 일체화된 보안 대응 체계 운영
  • 경영진 보고와 전사 공지를 통한 기술 리스크 커뮤니케이션 주관
  • GPT·Kimi 계열 모델을 쿼리 확장, 카탈로그 매칭, 대규모 매칭 과제로 비교 평가하고 사내 공유용 리포트로 정리
  • 자연어 검색을 위한 구조화된 상품 지식 데이터 도입안을 분석해, 성공 조건 프레임워크와 Make-vs-Buy 전략 판단을 경영진에 브리핑
  • 상품 기획전에 LLM 기반 개인화를 적용하는 구조를 설계
  • 구매 고객은 카테고리 확장, 조회 후 미구매 고객은 같은 공간·용도까지만 확장하는 등 고객 상황별 추천 범위 정책 수립
  • 플랫폼 할인 구조 개선 과제에서 관련 부서 간 조율과 의사결정 지원
  • 복잡한 논의를 한 장 요약으로 정리해 경영진 보고
  • 백엔드서비스개발유닛과 할인서비스개발유닛의 통합 설계
  • 기획과 개발이 한 조직에서 일하는 목적 조직 전환 검토, 고효율 카테고리(패션·반려동물·리빙·마트)를 파일럿 도메인으로 지정
  • 기획자의 개발유닛 합류에 맞춘 커뮤니케이션과 새 운영 모델 공지 설계
  • 성장과 커리어 중심의 1:1 대화 프레임 마련
  • 잘게 쪼개진 MSA의 통합과 레거시 제거 로드맵 수립
  • 기여도가 낮은 서비스·시스템을 선별해 단계적으로 종료하는 기준 마련
  • 모바일 조직 하반기 미션 정의, KMP 기반 Android·iOS 통합 검토
  • 업무용 Claude 스킬과 MCP 연동을 직접 개발 (뉴스 요약, 메신저 연동, 주간 업무 요약 자동 게시 등)
  • Playwright 기반 이커머스 판매자 검증 워크플로우 구현
  • SQL·데이터 파이프라인 문제를 직접 디버깅할 정도로 실무 감각 유지
